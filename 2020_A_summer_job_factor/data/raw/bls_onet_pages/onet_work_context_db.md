## Highlights of the O\*NET 31.0 Database

208 occupations are updated in the 31.0 release of the O\*NET database:

- Addition and update of **Abilities**, **Essential Skills**, and **Transferable Skills** data for 157 occupations
- Addition and update of **Task Statement ratings** (importance, relevance, and frequency) for 205 occupations
- Addition and update of **Emerging Tasks** for 49 occupations
- Addition and update of **Work Activities** and **Work Context** data for 177 occupations
- Addition and update of **Knowledge**, **Training and Work Experience**, and **Education** data for 168 occupations
- Addition and update of **Job Zones** data for 168 occupations
- Addition and update of **Detailed Work Activities** (DWAs) and linkages for 205 occupations
- Addition and update of **Job Titles** and **Sample of Reported Titles** for 208 occupations

## The O\*NET Database: A Primary Source of Occupational Information

The O\*NET database has a wide variety of worker and job oriented data categories. The [O\*NET Content Model](https://www.onetcenter.org/content.html) provides the framework that identifies and organizes this important information about work. The [O\*NET-SOC Occupation Taxonomy](https://www.onetcenter.org/taxonomy.html) covers work performed in the U.S. economy and defines the set of occupations for which data is collected.

The O\*NET Data Collection Program currently makes updates to the O\*NET Database on a quarterly basis, with a primary update occurring in the 3rd quarter of each year. Listings showing data updates by category or occupation are available on the [Occupation Update Summary](https://www.onetcenter.org/dataUpdates.html) page. See [Data Publication Schedule](https://www.onetcenter.org/ombclearance.html#schedule) for a listing of primary updates and collection history. Past releases of the O\*NET Database are available on the [Database Releases Archive](https://www.onetcenter.org/db_releases.html) page.

What is RDF?

Resource Description Framework (RDF) is a framework for expressing information about resources. Resources can be anything, including documents, physical objects, and abstract concepts. In O\*NET, resources include individual skills, occupations, and numeric data ratings.


RDF defines an interoperable way for different organizations and groups to link data together from multiple sources. Learn more from the W3C’s **[RDF Primer](https://www.w3.org/TR/rdf12-primer/) [external site](https://www.onetcenter.org/shared/exit?u=https%3A%2F%2Fwww.w3.org%2FTR%2Frdf12-primer%2F&t=RDF%20Primer&c=c3ee4)**.

## Machine-Discoverable Data

The O\*NET Database contains over 1 million RDF resources representing skills, occupations, numeric data ratings, and more. Each of these resources is not only downloadable above, but accessible online through its identifier. In technical terms, every resource IRI is also a valid URL. Permanent IRIs are used which always point to the latest version of a resource, so automated tools can get up-to-date information on specific variables in real time.

The full database is machine discoverable through JSON-LD embedded within this page. Due to the size of the database, only a top-level Dublin Core Dataset is embedded. Automated tools can traverse the “hasPart” properties to discover the entire database.

The [O\*NET Content Model](https://www.onetcenter.org/content.html) includes worker- and job-oriented hierarchical taxonomies that can effectively serve as frameworks for organizing workforce competencies, credentials, and other work-relevant information.

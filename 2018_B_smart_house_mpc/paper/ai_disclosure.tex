\section{Purpose}
This report lists AI tools used while building AeroTherm-MPC.
It follows COMAP guidance on transparent AI disclosure.
Human teammates remain responsible for all submitted claims.

\section{Tools and roles}
\begin{itemize}[leftmargin=1.2em,itemsep=0.35em]
  \item \textbf{Cursor (Composer agent).}
  Assisted Python modules for the 2R2C thermal network ODEs,
  prediction matrices, and SciPy model predictive control (MPC) solver.
  Also drafted LaTeX structure under human review.
  \item \textbf{Local Ollama (\texttt{qwen2.5:7b}).}
  Designed for multi-inhabitant thermal preference dialogue
  in \texttt{cognitive\_thermostat.py}.
  Agents include EMS, senior, and parent personas.
  The locked dialogue file records a Mock fallback when Ollama was offline.
  The code path still prefers live Ollama when \texttt{localhost:11434} responds.
  \item \textbf{No cloud LLM for numeric invention.}
  KPI tables cite only local CSV/JSON under \texttt{results/}.
\end{itemize}

\section{What AI did not do}
\begin{itemize}[leftmargin=1.2em,itemsep=0.35em]
  \item AI did not fabricate locked simulation numbers.
  \item AI did not replace human judgment on design rules.
  \item The Summary Sheet numeric cells were checked against locked files by teammates.
  \item The homeowner advisory letter was edited by teammates for public clarity.
\end{itemize}
